# Campfire Guitar · tune up & learn songs

Learn easy guitar songs and keep your guitar in tune — one small app,
no account, no ads, everything on your phone.

Built as an installable web app (PWA), so it runs full-screen on an iPhone
like a native app — no App Store, no Mac, no developer account needed.

## What's inside

- **Tuner** — a real chromatic tuner that listens through the microphone
  (autocorrelation pitch detection) with a needle gauge, cents readout, and
  plain-language guidance per string ("E string — too low, tighten slowly").
  Tap any tuning peg to hear the target note as a synthesized plucked
  string (Karplus–Strong), so you can also tune entirely by ear.
- **Songs** — a ten-song path of public-domain classics, easiest first:
  from two-chord *Clementine* up to fingerpicked *House of the Rising Sun*.
  Chords sit right above the lyric syllable where they change, with strum
  patterns, tempo, per-song tips, auto-scroll for hands-free playing, and a
  "mark as learned" tracker.
- **Chords** — 17 open chords with finger-numbered diagrams. Tap one to
  see it big and *hear* how it should sound (each string is synthesized
  and strummed).
- **Beat** — a metronome (40–208 BPM) with tap tempo, accented downbeats,
  and 2/4 · 3/4 · 4/4 · 6/8-friendly beat counts.
- Progress and settings live only on the device (localStorage); nothing is
  uploaded anywhere. Works offline after first load (service worker) —
  though the mic tuner needs the page served over HTTPS.

## Install on iPhone

1. Open the app's URL in **Safari**.
2. Tap the **Share** button, then **Add to Home Screen**.
3. Launch it from the home screen — it opens full-screen like a native app.
4. The first time you start the tuner, allow microphone access.
